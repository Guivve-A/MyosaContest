# PneumoCoach · companion application

Interface for the respiratory rehabilitation wearable.
Next.js 16 · React 19 · Tailwind 4 · shadcn/ui (Base UI).

```bash
npm install
npm run dev
```

## How it is organised

```
src/lib/telemetry.ts        data contract: classes, window, thresholds
src/lib/ble.ts              BLE transport plus breathing simulator
src/lib/ble-real.ts         Web Bluetooth transport against the device
src/hooks/use-telemetry.tsx session state shared by the three tabs
src/components/viz/         SVG traces, bars, columns
src/components/resumen/     biofeedback dashboard and breathing orb
src/components/sensores/    IMU channels and BMP180 context
src/components/aprendizaje/ progress, gamification and history
src/components/tutorial/    guided first-run walkthrough
src/components/shell/       header, BLE status and navigation
src/components/ui/          shadcn — never hand-edited, regenerated by the CLI
```

## Decisions worth knowing before touching the code

**`src/lib/telemetry.ts` is a mirror, not a source.** The classes, the 12 s
window with its 3 s hop, the 0.60 confidence floor and the 29 features all come
from `ml/pneumocoach/config.py`. When something changes there, it is reflected
here; never the other way round.

**The transport sits behind an interface.** Web Bluetooth does not exist in
Safari or Firefox, and the demo has to be possible without paired hardware.
`MockTransport` reproduces the real mechanics — including the
inspiration/expiration asymmetry — and `WebBluetoothTransport` speaks the
firmware's UUIDs.

**Simulated data is never implied, it is stated.** While the mock transport is
in use the header carries a `SIMULADO` badge. A demo that cannot tell a
measurement from a simulation is precisely what this project spends its effort
avoiding.

**The app stays quiet when the model is unsure.** Below the confidence floor no
verdict is displayed. A wrong correction given to a patient who is learning to
breathe is worse than saying nothing.

**The orb breathes at the patient's rate.** The transition duration is derived
from the measured BPM; it is not a fixed value. An animation that does not match
the real breath competes with it instead of guiding it.

**All motion is disabled under `prefers-reduced-motion`.** For someone who is
breathless, a pulsing interface can be counterproductive.

## Palette

Derived from the reference photograph. Each token maps to a specific element of
that image: the amber of the lens is the accent, the blue-violet of the dark
frame squares is the ink, and the neutrals come from the travertine.

## Demonstration control

With the device connected, a dotted bar appears that forces the simulated
technique. It exists so the demo can be rehearsed without a patient. **It must
not exist in production**: the technique is decided by the model on the device,
not by the interface.
